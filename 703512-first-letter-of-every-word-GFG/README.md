# [First Letter of Every Word](https://www.geeksforgeeks.org/problems/print-first-letter-of-every-word-in-the-string3632/1)
## Easy

Given a string s, the task is to create a string with the first letter of every word in the string. The string s contains lower case English alphabets and its words have a single space between them.&nbsp;
Examples:
Input: s = "geeks for geeks"
Output: gfgExplanation: First word starts at index 0, take 'g' After first space, next word starts with 'f'After second space, next word starts with 'g'
Input: s = "bad is good"
Output: big
Constraints:1 ≤ |s| ≤ 105
