<h2><a href="https://www.geeksforgeeks.org/problems/largest-number-with-given-sum-1587115620/1">Largest n Digit Number with Given Digit Sum</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p data-start="84" data-end="649"><span style="font-size: 14pt;">Given two integers <strong>n</strong> and <strong data-start="244" data-end="249">s</strong>. find the largest possible number that can be formed using exactly <strong>n </strong>digits such that sum of the digits equals <strong>s</strong>.&nbsp;</span></p>
<ul>
<li data-start="84" data-end="649"><span style="font-size: 14pt;">If it is not possible to construct such a number, return "-1".</span></li>
<li data-start="84" data-end="649"><span style="font-size: 14pt;">Return the result as a string. </span></li>
</ul>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><strong><span style="font-size: 18px;">Input: </span></strong><span style="font-size: 18px;">n = 5, s = 12
<strong>Output: </strong>93000<strong>
Explanation:
</strong>Sum of elements is 12. Largest possible 5 digit number is 93000 with sum 12.</span>
</pre>
<pre><strong><span style="font-size: 18px;">Input: </span></strong><span style="font-size: 18px;">n = 3, s = 29
<strong>Output: </strong>-1<strong>
Explanation:
</strong>There is no such three digit number whose sum is 29.</span></pre>
