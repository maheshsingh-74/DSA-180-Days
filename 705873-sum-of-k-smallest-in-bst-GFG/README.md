# [Sum of k smallest in BST](https://www.geeksforgeeks.org/problems/sum-of-k-smallest-elements-in-bst3029/1)
## Easy
&nbsp;Given a Binary Search Tree, find sum of k smallest nodes in it. You may assume that k is always smaller than or equal to size of the tree.
Examples:
Input: k = 3 
Output: 22
Explanation: Sum of 3 smallest elements are: 4 + 8 + 10 = 22
Input: k = 2 &nbsp;Output: 9
Explanation: The sum of two smallest elements is 4+5=9
Constraints:1 ≤ Number of nodes in BST ≤ 1001 ≤ K ≤ n
