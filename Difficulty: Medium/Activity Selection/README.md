<h2><a href="https://www.geeksforgeeks.org/problems/activity-selection-1587115620/1">Activity Selection</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given two arrays<strong> start[] </strong>and <strong>finish[]</strong>, where start[i] and finish[i] represent the start time and finish time of the i-th activity, find the maximum number of activities that a single person can perform.</span></p>
<p><span style="font-size: 14pt;">A person can perform only one activity at a time, and no two selected activities can overlap. If an activity finishes at time x, the next selected activity must start at a time greater than x.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong><strong>Input: </strong></strong>start[] = [1, 3, 0, 5, 8, 5], finish[] = [2, 4, 6, 7, 9, 9]<br><strong><strong>Output: </strong></strong>4<br><strong><strong>Explanation:</strong></strong> </span><span style="font-size: 18.6667px;">One possible selection is activities {0, 1, 3, 4} with time intervals (1, 2), (3, 4), (5, 7), and (8, 9). Each activity starts after the previous one finishes, so a total of 4 activities can be performed.</span></pre>
<pre><span style="font-size: 14pt;"><strong><strong>Input:</strong></strong> start[] = [10, 12, 20], finish[] = [20, 25, 30]<br><strong><strong>Output: </strong></strong>1<br><strong><strong>Explanation: </strong></strong></span><span style="font-size: 18.6667px;">Activity 0 finishes at time 20, and activity 2 also starts at time 20. Since the next activity must start after the previous one finishes, they cannot both be selected. Hence, only one activity can be performed.</span></pre>
