# [Kth Largest in BST](https://www.geeksforgeeks.org/problems/kth-largest-element-in-bst/1)
## Easy
Given the root of a Binary Search Tree (BST) and an integer k, find the k-th largest element in the BST without modifying its structure.
Examples:
Input: root = [4, 2, 9], k = 2
Output: 4Explanation: The second largest element is 4.
Input: root = [10, 2, 11, 1, 5, N, N, N, N, 3, 6, N, 4], k = 7
 Output: 2Explanation: The 7th largest element is 2.
Input: root = [4, 2, 9], k = 3

Output: 2Explanation: The 3rd largest element is 2.
Constraints:1&nbsp;≤&nbsp;number of nodes&nbsp;≤&nbsp;1051&nbsp;≤&nbsp;node-&gt;data&nbsp;≤&nbsp;1051&nbsp;≤ k&nbsp;≤&nbsp;number of nodes
