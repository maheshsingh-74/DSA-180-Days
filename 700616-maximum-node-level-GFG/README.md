# [Maximum Node Level](https://www.geeksforgeeks.org/problems/maximum-node-level/1)
## Easy
Given a Binary tree, find the level in the binary tree which has the maximum number of nodes. Root is considered at level 0.
Examples:
Input: root = [2, 1, 3, 4, 6, N, 8, N, N, 5]    &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 
Output: 2
Explanation: The level 2 with nodes 4, 6 and 8 is the level with maximum number of nodes. 
Input: root = [2, 1, 3, 4, 7, N, 8, N, N, 5]                                    
Output: 2
Explanation: The level 2 with nodes 4, 7 and 8 is the level with maximum number of nodes. 
Constraints:1 ≤ number of nodes ≤ 1051 ≤ node -&gt; data ≤ 105
