# [Maximum Depth Of Binary Tree](https://www.geeksforgeeks.org/problems/maximum-depth-of-binary-tree/1)
## Easy
Given a binary tree, find its maximum&nbsp;depth. A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.
Examples :
Input: root = [1, 3, 2, 4, N, N, N] &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Output: 3Explanation: Maximum depth is for leaf 4, which is 3.
Input: root = [10, 20, 30, N, 40, N, 60, N, N, 2, N, N, N]
 Output: 4
Explanation: Maximum depth is for leaf 2, which is 4

Constraints:1 ≤ n ≤ 105
